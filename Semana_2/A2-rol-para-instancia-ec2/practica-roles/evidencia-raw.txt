PARTE 2: ESCRIBIR LAS DOS POLÍTICAS

Paso 4: Crea el archivo confianza.json con una política que permita asumir el rol solo al servicio EC2.

{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Principal": { "Service": "ec2.amazonaws.com" },
    "Action": "sts:AssumeRole"
  }]
}

Paso 5: Crea el archivo permisos.json con una política que permita solo leer objetos de tu bucket.

{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Action": ["s3:GetObject"],
    "Resource": "arn:aws:s3:::reportes-juan-1125/*"
  }]
}

Paso 6: Comprueba que los dos archivos son JSON válido.

PS D:\Juan-Canas-D\Escritorio\AWS-Cloud\RIWI-AWS\04-ROLES-IAM\practica-roles> Get-Content confianza.json -Raw | ConvertFrom-Json

PS D:\Juan-Canas-D\Escritorio\AWS-Cloud\RIWI-AWS\04-ROLES-IAM\practica-roles> Get-Content permisos.json -Raw | ConvertFrom-Json
